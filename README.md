# Invoice Generator

Professional invoice generator that creates PDF-ready HTML invoices.

## Features
- Interactive CLI interface
- Automatic line item calculation
- Tax calculation
- Professional HTML output
- Easy to customize

## Installation
```bash
npm install
```

## Usage
```bash
node invoice.js
```

## Sample Invoice
Run the sample generator:
```bash
node generate-sample.js
```
