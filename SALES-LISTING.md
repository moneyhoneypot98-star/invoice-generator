## Description

### The problem
You finished the work. Now you need to bill the client. Subscription invoicing apps want $15–30 EVERY MONTH to draw a table and do multiplication.

### The fix
Invoice Generator is a one-time-download tool that asks you a few questions, does all the math (line items, quantities, sales tax), and produces a clean, professional, print-ready invoice. Open it in any browser → Print → Save as PDF → send.

### Features
- ✅ Interactive mode — guided prompts, no learning curve
- ✅ Automation mode — generate invoices from JSON (perfect if you batch-bill clients)
- ✅ Automatic math — subtotals, per-item totals, sales tax, grand total
- ✅ Professional output — clean HTML that prints to perfect PDFs
- ✅ 100% offline — your client and billing data never leaves your computer
- ✅ No account, no subscription, no watermark, no limits

### What's included
- invoice.js — the tool (interactive + JSON batch mode)
- sample-invoice.html — see the output before you buy
- example-data.json — JSON template for automation mode
- README — 2-minute setup guide

### Requirements
Node.js (free, nodejs.org). Runs on Windows, Mac, Linux.

### FAQ
**Is this a subscription?** No. One payment, yours forever, unlimited invoices.
**Can I customize the look?** Yes — the output is standard HTML/CSS, edit freely.
**Do you see my invoices?** No. Everything runs on your machine.
**Refunds?** Check the sample invoice first — that's exactly what you'll get.
